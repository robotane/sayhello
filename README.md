# sayhello

Application "hello world" réalisée en suivant le tutoriel JCloudify (Java/Gradle),
utilisée pour se familiariser avec l'outillage JCloudify.

## Build

```bash
./gradlew build
```

Projet jumeau de [hellonew](https://github.com/robotane/hellonew), issu du même
tutoriel de prise en main.
